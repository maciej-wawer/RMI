# WikiRMI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a distributed wiki (admin creates page skeletons + users; users browse/search/edit pages) in Java RMI with a Swing GUI, JSON persistence, and a fine-grained, deadlock-free concurrency model.

**Architecture:** Three-tier RMI. `common/` holds the remote interfaces + Serializable DTOs + exceptions. `server/` implements the service over a `WikiStore` that does all concurrency control (per-page `ReentrantReadWriteLock` + an edit-lease state machine), with a daemon reaping expired leases, JSON write-through persistence, sessions guarded by a `Semaphore`, and RMI callbacks for live updates. `client/` is a Swing GUI that talks to the server only through a `WikiClientController`.

**Tech Stack:** Java 17 (Java 8 compatible), `java.rmi`, `java.util.concurrent`, Swing. **No external dependencies** — hand-rolled JSON, hand-rolled test harness. Build with `javac`/`java` + PowerShell scripts.

**Conventions:**
- Package root `wikirmi`. Source in `src/`, tests in `test/`, compiled to `out/`.
- User-facing messages (exceptions) in Polish; identifiers/comments in English.
- "Run the build" = `./build.ps1`; "run a class" = `java -cp out <fqcn>`.
- TDD red-state: tests reference a real (stub) API so they **compile but fail at runtime**, then we implement. The test harness is plain Java (Task 2).
- Commit after every task with the message shown.

**Files:** Create `src/wikirmi/server/store/WikiStore.java`; Test `test/wikirmi/test/CreatePageRaceTest.java`.

- [ ] **Step 1: `WikiStore.java` (part 1 — state + mappers + user/page CRUD + getPage).** Full class will grow across Tasks 3.3–3.6; create it now with these members:
```java
package wikirmi.server.store;
import wikirmi.common.Role; import wikirmi.common.dto.*; import wikirmi.common.exceptions.*;
import wikirmi.server.model.*;
import java.util.*; import java.util.concurrent.ConcurrentHashMap; import java.util.concurrent.locks.ReentrantReadWriteLock;
public class WikiStore {
    private final ConcurrentHashMap<String,Page> pages = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String,User> users = new ConcurrentHashMap<>();
    private final long leaseMs; private final Clock clock;
    public WikiStore(long leaseMs, Clock clock){ this.leaseMs=leaseMs; this.clock=clock; }

    // ---- validation ----
    private static void requireTitle(String t) throws ValidationException {
        if (t==null || t.trim().isEmpty()) throw new ValidationException("Tytuł strony nie może być pusty.");
        if (t.length()>120) throw new ValidationException("Tytuł jest za długi (max 120).");
    }
    private static void requireContent(String c) throws ValidationException {
        if (c==null) throw new ValidationException("Treść nie może być pusta.");
        if (c.length()>100000) throw new ValidationException("Treść jest za długa.");
    }

    // ---- users (accounts; sessions live in SessionManager) ----
    public void addUser(User u) { users.put(u.username(), u); }     // used by persistence/seed
    public User getUser(String username) { return users.get(username); }
    public void createUser(String username,String salt,String hash,Role role) throws ValidationException {
        if (username==null || username.trim().isEmpty()) throw new ValidationException("Nazwa użytkownika nie może być pusta.");
        if (users.putIfAbsent(username, new User(username,salt,hash,role)) != null)
            throw new ValidationException("Użytkownik '"+username+"' już istnieje.");
    }
    public void deleteUser(String username) throws NotFoundException {
        if (users.remove(username)==null) throw new NotFoundException("Nie znaleziono użytkownika: "+username);
    }
    public List<UserDTO> listUsers(){
        List<UserDTO> out=new ArrayList<>();
        for (User u: users.values()) out.add(new UserDTO(u.username(), u.role()));
        out.sort(Comparator.comparing(UserDTO::getUsername)); return out;
    }
    public Collection<User> allUsers(){ return users.values(); }      // persistence snapshot

    // ---- pages: create / delete / read ----
    public PageDTO createPage(String title,String content,String editor) throws ValidationException {
        requireTitle(title); String body = content==null? "" : content; requireContent(body);
        long now = clock.now();
        Page p = new Page(title, body, 0, editor, now);
        if (pages.putIfAbsent(title, p) != null) throw new ValidationException("Strona '"+title+"' już istnieje.");
        return toDTO(p, now);
    }
    public void deletePage(String title) throws NotFoundException {
        if (pages.remove(title)==null) throw new NotFoundException("Nie znaleziono strony: "+title);
    }
    public void putPage(Page p){ pages.put(p.title(), p); }            // persistence load
    public Collection<Page> allPages(){ return pages.values(); }      // persistence snapshot

    private Page require(String title) throws NotFoundException {
        Page p = pages.get(title); if (p==null) throw new NotFoundException("Nie znaleziono strony: "+title); return p;
    }
    public PageDTO getPage(String title) throws NotFoundException {
        Page p = require(title); p.lock().readLock().lock();
        try { return toDTO(p, clock.now()); } finally { p.lock().readLock().unlock(); }
    }
    public List<PageSummaryDTO> listPages(){
        List<PageSummaryDTO> out=new ArrayList<>(); long now=clock.now();
        for (Page p: pages.values()){ p.lock().readLock().lock(); try { out.add(toSummary(p, now)); } finally { p.lock().readLock().unlock(); } }
        out.sort(Comparator.comparing(PageSummaryDTO::getTitle)); return out;
    }

    // ---- mappers (callers hold the appropriate lock) ----
    private PageDTO toDTO(Page p, long now){
        return new PageDTO(p.title(), p.content(), p.version(), p.lastEditor(), p.lastModified(), toLockInfo(p.editLock(), now));
    }
    private PageSummaryDTO toSummary(Page p, long now){
        EditLock l=p.editLock(); String by=(l!=null && !l.isExpired(now))? l.holderName() : null;
        return new PageSummaryDTO(p.title(), p.version(), by, p.lastModified());
    }
    private LockInfoDTO toLockInfo(EditLock l, long now){
        if (l==null || l.isExpired(now)) return null;
        return new LockInfoDTO(l.holderName(), l.acquiredAt(), l.expiresAt(), Math.max(0, l.expiresAt()-now));
    }
}
```

- [ ] **Step 1: Add to `WikiStore`:**
```java
    public LockInfoDTO acquireEditLock(String title,String token,String userName) throws NotFoundException, PageLockedException {
        Page p=require(title); long now=clock.now(); p.lock().writeLock().lock();
        try {
            EditLock cur=p.editLock();
            if (cur!=null && !cur.isExpired(now) && !cur.heldBy(token))
                throw new PageLockedException(cur.holderName(), Math.max(0,(cur.expiresAt()-now))/1000);
            EditLock l=new EditLock(token,userName,now,now+leaseMs); p.setEditLock(l);
            return toLockInfo(l, now);
```

```java
package wikirmi.server.auth;
import java.security.MessageDigest; import java.security.SecureRandom; import java.nio.charset.StandardCharsets;
public final class PasswordHasher {
    private static final SecureRandom RNG=new SecureRandom();
    public static String newSalt(){ byte[] b=new byte[16]; RNG.nextBytes(b); return toHex(b); }
    public static String hash(String password,String salt){
        try { MessageDigest md=MessageDigest.getInstance("SHA-256"); md.update(hex(salt)); 
            return toHex(md.digest(password.getBytes(StandardCharsets.UTF_8))); }
        catch(Exception e){ throw new RuntimeException(e); }
    }
    public static boolean verify(String password,String salt,String expectedHash){
        return MessageDigest.isEqual(hex(hash(password,salt)), hex(expectedHash)); // constant-time
    }
    private static String toHex(byte[] b){ StringBuilder s=new StringBuilder(); for(byte x:b) s.append(String.format("%02x",x)); return s.toString(); }
    private static byte[] hex(String h){ int n=h.length()/2; byte[] b=new byte[n]; for(int i=0;i<n;i++) b[i]=(byte)Integer.parseInt(h.substring(2*i,2*i+2),16); return b; }
```

```java
package wikirmi.server.auth;
import wikirmi.common.Role; import wikirmi.common.exceptions.AuthenticationException;
import java.util.UUID; import java.util.concurrent.*;
public class SessionManager {
    public static final class Session { public final String token,username; public final Role role; public volatile long lastSeen;
        Session(String t,String u,Role r,long now){token=t;username=u;role=r;lastSeen=now;} }
    private final ConcurrentHashMap<String,Session> sessions=new ConcurrentHashMap<>();
    private final Semaphore permits;
    public SessionManager(int maxClients){ this.permits=new Semaphore(maxClients); }
    public String open(String username,Role role) throws AuthenticationException {
        if(!permits.tryAcquire()) throw new AuthenticationException("Serwer jest pełny — przekroczono limit klientów.");
        String tok=UUID.randomUUID().toString();
        sessions.put(tok,new Session(tok,username,role,System.currentTimeMillis())); return tok;
    }
    public Session require(String token) throws AuthenticationException {
        Session s=(token==null)?null:sessions.get(token);
        if(s==null) throw new AuthenticationException("Sesja wygasła lub jest nieprawidłowa. Zaloguj się ponownie.");
        s.lastSeen=System.currentTimeMillis(); return s;
    }
    public void requireAdmin(String token) throws AuthenticationException, wikirmi.common.exceptions.AuthorizationException {
        if(require(token).role!=Role.ADMIN) throw new wikirmi.common.exceptions.AuthorizationException("Operacja dozwolona tylko dla administratora.");
    }
    public void close(String token){ if(token!=null && sessions.remove(token)!=null) permits.release(); }
    public int active(){ return sessions.size(); }
}
```

```java
        notify.pageCreated(new PageSummaryDTO(p.getTitle(),p.getVersion(),null,p.getLastModified()));
    }
    public PageDTO savePage(String tok,String title,String content,long base) throws RemoteException, WikiException {
        SessionManager.Session s=sessions.require(tok);
        PageDTO p=store.savePage(title,s.token,s.username,content,base); persist.run();
        notify.pageChanged(new PageSummaryDTO(p.getTitle(),p.getVersion(),null,p.getLastModified()));
        return p;
    }
```
(`acquireEditLock`/`renewEditLock`/`releaseEditLock` fire `notify.lockChanged`; browse/search/get/history just `sessions.require` then delegate.)

```java
package wikirmi.client.gui;
import javax.swing.*; import java.util.concurrent.Callable;
public final class UiUtils {
    public interface Sink<T> { void ok(T v); }
    public static <T> void async(JComponent owner, Callable<T> call, Sink<T> onOk){
        new SwingWorker<T,Void>(){ Exception err;
            protected T doInBackground(){ try{ return call.call(); } catch(Exception e){ err=e; return null; } }
            protected void done(){ if(err!=null) error(owner, err); else onOk.ok(get_()); }
            T get_(){ try{ return get(); }catch(Exception e){ return null; } }
        }.execute();
    }
    public static void error(java.awt.Component c, Throwable t){
        Throwable r=(t.getCause()!=null && t.getCause() instanceof Exception)? t.getCause(): t;
        JOptionPane.showMessageDialog(c, r.getMessage()==null? r.toString(): r.getMessage(), "Błąd", JOptionPane.ERROR_MESSAGE);
    }
}
```
